# Google Fonts onboarding materials

These files are prepared for upstream review. They do not modify Google's production subsetter or designer catalog.

## Latin subset correction

`latin-subset-fix.patch` targets googlefonts/nam-files commit `533d55837754572ad40588fc1821c21adbf65b3e`. Apply to `subsets-input/latin-ext_unique-glyphs.nam`, regenerate the derived data using that repository's documented process, and validate its tests before submitting.

The four additions are U+0302, U+0331, U+1EBC and U+1EBD. The first two are combining marks used by supported Latin-script languages. E with tilde is also used beyond Vietnamese; excluding it from latin-ext makes Guarani, Yanomamö and Ticuna samples fail despite the glyph being present in the font. Fontspector 1.9.1 currently produces ten missing-subsetted messages for these four codepoints in Leon Sans 2.003. No language samples were removed, no font codepoints were deleted, and no check was excluded to hide the issue.

The broader unreachable-codepoint list includes mathematical signs, arrows and other symbols. It needs an explicit serving decision with the Google Fonts maintainer; the font does not claim full Greek, Vietnamese or mathematical-layout support. The full-repertoire WOFF2 in `fonts/webfonts` preserves all current font characters for self-hosting.

## Verified subset patch revision (2026-11-14)

The previous input-only proposal was incomplete: adding U+1EBC/U+1EBD did not override the broad negative range. The revised patch splits that exclusion and includes the actual output regenerated by upstream `scripts/preprocess_namfile.py`. Its exact codepoint delta is +U+0302, +U+0331, +U+1EBC and +U+1EBD; no codepoints are removed. These additions cover the codepoints reported in all ten current missing-subsetted failures.

This is a proposal, not a change to the official Fontspector binary or Google production. Upstream's unchanged overlap test has fifteen pre-existing findings at the pinned commit; the proposal adds two intentional Latin/Vietnamese shared-codepoint decisions (E-tilde). The test was not edited to hide those findings. Maintainer agreement is required before merging/deployment. Evidence is in `output/font-release-audit-2026-11-14/`.

## Strict local release gate

`python scripts/qa.py --fontspector /path/to/fontspector --output output/qa` records input and report hashes. `python scripts/check_release.py --qa-directory output/qa` rejects offline runs, changed packages, missing evidence, unsuccessful runs, and any WARN/FAIL/ERROR/FATAL. It intentionally remains blocked while current upstream issues are unresolved. Do not describe the proposal validation as an official clean run.

After reviewed sources are committed, create the development package, rerun QA on that exact package, then use `python scripts/prepare_metadata.py --release --qa-directory output/qa`. A clean Git tree alone no longer sets `release_ready` true. This technical gate does not grant Google Fonts design approval.
