Leon Sans is a geometric sans-serif typeface designed by Jongmin Kim in 2019 to celebrate the birth of his son Leon. Its original drawing system was created in code.

Version 2.0 provides a variable TrueType font with nine named weights from Thin to Black. The design retains geometric proportions while refining stroke joins, curved transitions and optical spacing. The family supports the Google Fonts Latin Core character set and includes combining-accent positioning.

To contribute, visit github.com/cmiscm/leonsansfont. The original animated JavaScript typeface is maintained separately.
